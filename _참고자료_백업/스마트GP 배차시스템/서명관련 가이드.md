# 지피로지스 맞춤형 전자서약 & 서류양식 빌더 시스템 완료 보고

## 1. 시스템 개요
현장이나 안전교육마다 서식과 서명 위치가 달라 매번 코딩을 수정해야 했던 문제를 원천 해결하기 위해, **관리자가 관제 센터에서 필요에 따라 2가지 방식(텍스트 교육형 vs 서류 사진 양식형) 중 하나를 선택해 1분 만에 전자서명 링크를 발행하고 카톡 전송 및 엑셀 출력을 할 수 있는 「올인원 전자서명 빌더 시스템」**을 구축 완료하였습니다.

---

## 2. 2가지 서명 제작 모드 완벽 지원

### 📌 [모드 1] 텍스트 교육/서약형 (포항제철소 안전교육 스타일)
- **사용 시점**: 안전교육 영상 시청 확인, 사내 안전수칙 서약, 온열질환 예방 수칙 등
- **특징**: 서류 사진 파일 불필요! 제목과 안내/서약 내용만 적으면 모바일 서명 페이지 즉시 생성
- **결과물**: 실시간 서명자 명단 + 자필 서명 이미지 + 원청 제출용 엑셀 명부

### 📌 [모드 2] 서류 사진 양식형 (LH 명지 확약서 스타일)
- **사용 시점**: 원청(LH, 제철소 등)에서 제공한 원본 서류 사진 양식에 기사님 서명/이름을 날인해 제출해야 할 때
- **특징**: 서류 사진(JPG/PNG)을 올리고, 마우스로 서류 위의 `[서명란]`, `[성명]`, `[차량번호]`, `[날짜]` 위치를 콕 찍어 배치
- **결과물**: 기사님이 서명하면 지정된 위치에 1픽셀 오차 없이 이름과 서명이 쏙 들어간 **최종 완성본 서류 이미지 자동 생성** + 엑셀 명부

## 3. 주요 구현 기능 및 가이드

### 1) 관제 센터: 📝 [서약·양식 빌더] 메뉴 신설 ([`control.html`](file:///c:/%EC%8A%A4%EB%A7%88%ED%8A%B8GP%20%EB%B0%B0%EC%B0%A8%EC%8B%9C%EC%8A%A4%ED%85%9C%20%ED%99%95%EC%95%BD%EC%84%9C/control.html))
- **[+ 새 서명 양식 만들기] 버튼**: 텍스트형 또는 서류 사진형을 선택하여 1분 만에 양식 등록
- **[카톡 문구 복사] 버튼**: 기사님이 무엇을 서명하는지 단번에 알 수 있도록 **서류명 + 안내문 + 링크가 포함된 완성형 카톡 메시지** 원클릭 복사
- **[제출자 목록] 버튼**: 해당 양식에 서명한 기사님들의 실시간 목록 조회, 완성 서류/서명 확인 및 개별 다운로드
- **[엑셀 출력] 버튼**: 해당 양식의 서명자 명단을 엑셀(`.xlsx`) 파일로 즉시 다운로드

### 2) 운전자용: 범용 전자서명 모바일 페이지 ([`sign_doc.html`](file:///c:/%EC%8A%A4%EB%A7%88%ED%8A%B8GP%20%EB%B0%B0%EC%B0%A8%EC%8B%9C%EC%8A%A4%ED%85%9C%20%ED%99%95%EC%95%BD%EC%84%9C/sign_doc.html))
- 접속 주소: `https://smartgp-f7dc0.web.app/doc?id=양식ID`
- 상단에 서명 목적과 서류 안내문 명시
- 서류 사진 양식인 경우 원본 서류 돋보기 확대 뷰어 제공
- 모바일 자필 서명 패드 및 HTML5 Canvas 자동 정밀 합성 엔진 탑재
